# Aurora UI

A modern **C++20 retained-mode UI library**, architecturally comparable to **Qt 6**:
object tree, signals & slots, events, layouts, widgets, 2D painting, styles/themes,
timers and an event loop — in a compact, dependency-free, testable package.

![Aurora UI demo](docs/demo.bmp)

## Feature comparison with Qt 6

| Capability | Qt 6 | Aurora UI |
|---|---|---|
| Object tree / ownership | `QObject` parent-child | `aui::Object` |
| Signals & slots | `QObject::connect` / `moc` | `aui::Signal<...>` — no moc, pure C++20 |
| Properties | `Q_PROPERTY` | `aui::Property<T>` with change signals & bindings |
| Events | `QEvent` hierarchy | `aui::Event`, `MouseEvent`, `KeyEvent`, `PaintEvent`... |
| Event loop / timers | `QEventLoop`, `QTimer` | `aui::EventLoop`, `aui::Timer` |
| Widgets | `QWidget`, `QPushButton`, ... | `aui::Widget`, `aui::Button`, ... |
| Layouts | `QBoxLayout`, `QGridLayout` | `aui::BoxLayout`, `aui::GridLayout` |
| Painting | `QPainter` | `aui::Painter` (software rasterizer) |
| Styling | `QPalette`, QSS | `aui::Style` light/dark themes |
| Fonts | `QFont` / FreeType | built-in bitmap font atlas (generated by `tools/gen_font.py`) |

## Building

```sh
cmake -B build && cmake --build build -j
ctest --test-dir build
./build/demo      # renders docs/demo.bmp headlessly
```

No external dependencies beyond a C++20 compiler. The software backend renders
into an in-memory image, so everything runs headless (CI-friendly); a platform
backend can be added by feeding `aui::Event`s into the widget tree.

## Quick example

```cpp
#include <aurora/aurora.hpp>
using namespace aui;

Widget window;
window.setGeometry({0, 0, 320, 200});
auto* layout = new BoxLayout(BoxLayout::Vertical, &window);

auto* label = new Label("Hello, Aurora!");
auto* button = new Button("Click me");
layout->add(label);
layout->add(button);

int clicks = 0;
connect(button->clicked, [&] { label->setText("Clicked " + std::to_string(++clicks)); });

Image img = Application::renderToImage(window);   // headless render
img.save("out.bmp");
```

## Layout of the repository

- `include/aurora/core` — Object, Signal, Event, Property, EventLoop/Timer, Geometry
- `include/aurora/paint` — Color, Image, Painter, FontData
- `include/aurora/style` — Style, light/dark palettes
- `include/aurora/layout` — BoxLayout, GridLayout
- `include/aurora/widgets` — Widget, Label, Button, CheckBox, Slider, LineEdit,
  ProgressBar, ListWidget, Application
- `examples/` — demo, todo app, widget gallery (all render headlessly to BMP)
- `tests/` — core & widget test suites
- `tools/gen_font.py` — regenerates the embedded font atlas from DejaVu Sans
